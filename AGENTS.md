# Frontier Identity graphical standard

Before creating or revising graphical material, read [brand/README.md](brand/README.md). It is the current founder-approved standard for Frontier Identity, effective 2026-10-11.

- Use Horizon Modular v2, proposal 01, and the full FRONTIER IDENTITY wordmark. Use the designated assets in `brand/assets/` and preserve their geometry.
- Use `brand/theme.css` semantic tokens and `brand/examples/` component patterns. In light mode, primary actions use `#FF6B21` with `#0B0D0F` text and `#747E88` borders; links and focus use `#935100`. Reserve `#B42318` for errors. Do not restore the superseded `#B84000` action treatment.
- Match logo variants to their background. Follow `brand/repository-readme-template.md` for repository headers.
- Verify changed compositions for text and control contrast, focus, layout and asset references. Follow `brand/VERIFICATION.md`; report the actual verification scope.
- Existing presentations retain their approved design until revised. Preserve the approved dark-mode palette unless the founder requests a revision.

Public branding instructions do not authorize publishing private company information.
